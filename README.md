# Go 语言深度剖析文档集

本项目是对 Go 语言底层实现原理的系统性学习笔记，涵盖**并发编程**、**内存管理**、**常用数据结构**、**关键字与语言特性**等核心主题。内容基于官方源码、经典文章（如左书祺《Go语言设计与实现》）以及实践总结，旨在帮助开发者深入理解 Go 运行时机制，写出更高效、更可靠的代码。

## 🎯 项目目标

- **源码级解析**：结合 Go 运行时源码，理解 `G-M-P` 调度、内存分配、GC 等核心机制。
- **性能优化指引**：总结常见陷阱与最佳实践，提供 CPU/内存问题排查流程。
- **面试与进阶**：覆盖高频面试点（slice 扩容、map 并发、channel 阻塞、defer 顺序等），助你攻克技术瓶颈。

## 🚀 如何使用

1. **阅读顺序建议**：
   - 先读 `Go基础/Go语言整体架构.md` 建立全局认知。
   - 然后深入 `并发编程/G-M-P.md` 理解调度器。
   - 接着按兴趣或工作需要选读内存管理、数据结构或关键字章节。

2. **结合源码**：
   - 文档中标注了对应的运行时文件（如 `runtime/proc.go`、`runtime/map.go`），建议打开源码对照学习。

3. **实践验证**：
   - 使用 `go build -gcflags="-m"` 观察逃逸分析。
   - 编写 benchmark 测试 slice 扩容、map 并发等。
   - 用 `pprof` 排查内存泄漏或 CPU 瓶颈。
